# Personalized_Technical_Tutor
A technical learning assistant that uses GPT and Llama to explain programming and machine learning concepts in simple language.

## Objective
To compare explanations from different language models and explore how previous conversations can improve the relevance of future responses.

## Steps Followed
1. Imported Python libraries and configured the OpenAI API.
2. Connected GPT using OpenAI and Llama using Ollama.
3. Prepared technical questions related to programming and machine learning.
4. Sent the same questions to both models.
5. Compared the explanations generated by each model.
6. Implemented streaming to display responses as they were generated.
7. Prepared previous technical conversations as background context.
8. Combined conversation history with new questions.
9. Updated the system prompt to generate clear, context-aware explanations.
10. Tested both models using the updated conversation context.

## Outcome
Created a technical tutor that compares GPT and Llama responses, supports streaming, and uses previous conversations to provide more relevant explanations.
